## Context
Continuing the `@layer components` design system. Surveyed real usage
first (`grep -rln 'class="[^"]*\bcard\b/badge\b/alert\b'`) before
building anything: `.card` has ZERO real usage anywhere (every apparent
match was a custom class like `.auth-card`/`.profile-card`, not
Bootstrap's `.card` — confirmed by reading the actual matched lines), so
skipped entirely. `.badge` is used with only 2 colors (success,
secondary — plus one dead class, see below). `.alert` is used with only
1 color (warning). Given this narrow, confirmed usage — unlike buttons,
used everywhere with many colors already — built only what's actually
needed rather than the full 8-color palette, to keep the exhaustive
verification burden proportional to real usage.

## Noticed, not fixed — a pre-existing dead class
`PageHome.vue` uses `class="badge text-bg-success-subtle"`. Checked:
`text-bg-success-subtle` is **not a real Bootstrap class** — grepped the
full compiled Bootstrap CSS output, zero matches for it anywhere (only
`bg-success-subtle` and `text-bg-success` exist as separate classes;
this combined name was never generated by Bootstrap). This badge has had
no color styling at all, silently, since before this migration started
— a pre-existing typo/dead-class bug, unrelated to Bootstrap removal.
Left as-is for behavioral parity: it did nothing under Bootstrap, so it
should keep doing nothing under Tailwind rather than silently gaining
new styling from a "fix" nobody asked for.
